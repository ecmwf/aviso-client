# Rust API reference

The full Rust API reference is generated by
[rustdoc](https://doc.rust-lang.org/rustdoc/) and hosted at
<https://docs.rs/aviso>. It lives close to the source so it stays in lock-step
with the released code.

For an overview and worked examples, read the
[library guide](../developers/lib-guide.md) in this book.

## Direct links

- [`aviso` crate root](https://docs.rs/aviso)
- [`AvisoClient`](https://docs.rs/aviso/latest/aviso/struct.AvisoClient.html):
  the main entry point.
- [`auth`](https://docs.rs/aviso/latest/aviso/auth/): the `AuthProvider` trait
  and the five built-in providers.
- [`watch`](https://docs.rs/aviso/latest/aviso/watch/): the `WatchRequest`
  builder, `NotificationStream`, and `Trigger` builders.
- [`state`](https://docs.rs/aviso/latest/aviso/state/): the `StateStore` trait,
  `MemoryStore`, and `JsonFileStore`.

docs.rs builds the documentation from the source on every release, so the
version you see there matches the version on crates.io.

## Building docs locally

If you have a checkout of the repository:

```bash
cargo doc --workspace --no-deps --open
```

This builds the API docs for the workspace and opens them in your browser.
